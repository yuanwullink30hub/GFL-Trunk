CORE PRINCIPLES EXTRACTED (8 TOTAL)
================================================================================

PRINCIPLE 1: TEXT CONTAINERS
├─ Font sizing: clamp(MIN, VIEWPORT%, MAX)
├─ Line height: 1.2 (headers), 1.4 (body)
├─ Width: 100% for full responsiveness
└─ All spacing uses clamp() for flexibility

PRINCIPLE 2: MEDIA CONTAINERS
├─ Max-width: clamp(400px, 90vw, 1200px) [CONSISTENT]
├─ Responsive gap: clamp(10px, 2vw, 20px) or clamp(20px, 5vw, 60px)
├─ Display: flex with proper alignment
└─ Positioning: relative container, absolute overlays

PRINCIPLE 3: SVG BUTTON CONTAINERS
├─ Base scale: scale(1.2) [ALWAYS - NON-NEGOTIABLE]
├─ Size: clamp(60px, 28vw, 220px) [CONSISTENT]
├─ Parent gap: clamp(20px, 5vw, 60px)
├─ Stroke: clamp(8px, 2vw, 15px)
└─ Each button: unique rotation + translation offsets

PRINCIPLE 4: TEXT POSITIONING
├─ Use calc() with documented components
├─ Example: calc(-9px - 200px + 75px - 100px + 25px)
├─ Each component represents a layer adjustment
└─ Width: 100% for responsiveness

PRINCIPLE 5: VIDEO OVERLAY
├─ Scale: 0.81 (proportional to button scale 1.2)
├─ Transform origin: top left [for predictable positioning]
├─ Blend mode: screen [additive light effect]
└─ Position: absolute with specific offsets

PRINCIPLE 6: CONTENT SECTIONS
├─ Container: max-w-4xl with mx-auto [readable width]
├─ Block spacing: space-y-6 [24px gap]
├─ Padding: pt-52 pb-20 px-6 [Tailwind classes]
└─ Images/videos: overflow-hidden rounded-2xl

PRINCIPLE 7: RESPONSIVE SPACING HIERARCHY
├─ Tight:       clamp(10px, 2vw, 20px)
├─ Medium:      clamp(20px, 5vw, 60px)    [Most common]
├─ Large:       clamp(30px, 7vw, 80px)
└─ Extra Large: clamp(40px, 10vw, 100px)

PRINCIPLE 8: Z-INDEX LAYERING
├─ Header: 9999 [always on top]
├─ Media: 8 [above text]
├─ Text: 2 [above background]
└─ Background: 1 [bottom layer]

Adding a New Text Container:
1. Open QUICK_REFERENCE.md
2. Find "1. Text Container (Header)" or "(Body)"
3. Copy the template
4. Replace content with your text
5. Done! Uses principles automatically

Adding a New SVG Button:
1. Open QUICK_REFERENCE.md
2. Find "5. SVG Button (Individual)"
3. Copy template and parent container
4. Change only: rotation angle, translateX, translateY
5. Ensure scale(1.2) is FIRST
6. Done!

Adding a New Media Container:
1. Open QUICK_REFERENCE.md
2. Find "3. Media Container (Flex Layout)"
3. Copy the container structure
4. Use clamp() for responsive gaps
5. Apply max-width constraint
6. Done!

Understanding Complex Positioning:
