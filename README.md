# GFL-Trunk

## Homepage
The homepage serves as the main landing page of the application, providing users with an overview of the project and quick access to key features. It includes navigation links and a welcoming introduction to guide visitors through the site.

## Contact Page
The contact page allows users to get in touch with the team. It features a contact form where visitors can submit their inquiries, feedback, or support requests. This page helps facilitate communication between users and the organization.
