Nebula Recorder

Captures a seamless, non-interactive nebula loop for the mobile background. Crossfade-loop technique → first and last frames match exactly.

Desktop uses 1.6 — lower = calmer color for mobile.
Desktop uses 1.8 — lower = thinner, less dense gas.
Adjust to taste — preview is live. Recording steps deterministically, so a 60 s clip takes ~30 s to capture.

Output downloads as nebula-mobile-loop.mp4 (or .webm if your browser can't encode mp4). Drop it into public/images/ and the mobile background picks it up. If it saved as .webm, also keep a .webm copy — the mobile <video> lists both sources.
